# UI slop checklist

From common critique of generated interfaces. Not failure-tested in this skill's scenarios, so use judgment. Each item is a question to ask of the design.

## Specific to this subject
- Could this page belong to any other company if the name were swapped? Build it from what makes this one different.
- Does the color and type come from the subject, rather than a default purple gradient on white?

## Layout
- Is the page more than hero, three identical cards, testimonials and CTA?
- Does hierarchy vary, with one thing clearly most important on each screen?
- Are shadows, rounded corners and gradients doing a job?

## Content
- Is every fact real? Mark unknown prices, hours and names as visible TODOs, and never invent testimonials or stats.
- Is the copy specific? Replace "seamless", "elevate", "unlock" and "powerful".
- Are emoji used in place of real icons? Replace them.

## Finish
- Do hover, focus, empty, loading and error states exist?
- Has it been checked at phone width and keyboard-only?
- Does every button do something real?
